# Sirius Face Animation

リアルタイムで表情が変化するアニメーション顔を表示するElectron + Next.jsアプリケーションです。キーボード操作やHTTPリクエストで表情を制御でき、ROS2システムとの双方向同期に対応しています。

## 📋 プロジェクト概要

- **プロジェクト名**: sirius-face
- **バージョン**: 1.0.0
- **開発者**: Ketan Patel
- **技術スタック**: Electron + Next.js + React + TypeScript + p5.js

## 🎭 主な機能

### 表情制御システム
- **9種類の表情**: neutral, happy, angry, sad, surprised, crying, hurt, wink, mouth3
- **リアルタイム切り替え**: キーボードまたはHTTP APIで即座に表情変更
- **アニメーション効果**: 表情変更時のジャンプエフェクト
- **自然な動作**: 自動瞬き、頭の微細な動き、呼吸のような揺れ

### 操作インターフェース
- **キーボードショートカット**: 数字キー1-8で表情切り替え、H/Qキーで機能切り替え
- **高度なタッチ操作**: 
  - 目のタップ: 痛がり反応（hurt表情、1秒後に復帰）
  - 鼻のタップ: 驚き反応（surprised表情、2秒後に復帰）
  - 四隅のタップ: 特殊表情（右下=mouth3、左下=wink、右上=crying、各3秒後に復帰）
  - 撫で動作: 長時間ドラッグで笑顔・ウィンク表情を段階的に変化
  - 目以外のタップ: 瞳孔がタップ方向に移動（3秒後に中央復帰）
- **過度なタップ防止**: 10秒間に10回以上の目タップで自動的に怒り・泣き表情
- **Picture-in-Picture**: Pキーでウィンドウ外表示
- **設定パネル**: HTTP接続設定の変更
- **デバッグ表示**: Hキーで当たり判定の可視化、Qキーで撫で時間表示切り替え

### ROS2連携機能（🆕 重要機能）
- **双方向同期**: ROS2サーバーとクライアント間で表情状態を同期
- **自動ポーリング**: 1秒間隔でサーバーから表情状態を取得
- **手動変更の反映**: キーボード・タッチ操作時にサーバーへ自動送信
- **競合回避**: 手動変更時は5秒間ポーリングを停止
- **リアルタイム同期**: 複数システム間での表情同期

## 🔄 ROS2同期の仕組み

### 通常の動作フロー
```
1. アプリ起動時 → ROS2サーバーから初期表情を取得
2. 1秒間隔 → サーバーから表情状態をポーリング
3. サーバー側で表情変更 → 自動的にクライアントに反映
```

### 手動変更時の動作フロー
```
1. キーボード（1-7）/ タッチ操作
2. ローカルで即座に表情変更
3. 同時にROS2サーバーにPOST送信
4. 5秒間ポーリング停止（競合回避）
5. 5秒後にポーリング再開
```

この仕組みにより、**手動で変更した表情がサーバーの古い表情で上書きされることを防ぎ**、常に最新の表情状態が維持されます。

## 🎮 操作方法

### キーボード操作
| キー | 表情 | 効果 |
|------|------|------|
| `1` | neutral | 通常の表情 |
| `2` | happy | 笑顔（上向きのカーブ） |
| `3` | angry | 怒り（下向きの眉、険しい目） |
| `4` | sad | 悲しみ（下向きの口） |
| `5` | surprised | 驚き（大きな目、丸い口） |
| `6` | crying | 泣き（涙のアニメーション付き） |
| `7` | hurt | 痛がる表情（波打つ口） |
| `8` | wink | ウィンク（左目を半目に） |
| `9` | mouth3 | 口開け表情（特殊な口の形） |
| `H` | - | 当たり判定可視化切り替え |
| `Q` | - | 撫で時間表示切り替え |
| `P` | - | Picture-in-Picture切り替え |
| `I` | - | 表示モード切り替え（顔⇔画像） |

### タッチ/マウス操作

#### 基本タップ操作
- **目のタップ**: 一時的に`hurt`表情に変化（1秒後に復帰）
- **鼻のタップ**: 一時的に`surprised`表情に変化（2秒後に復帰）

#### 画面四隅タップ（200×200ピクセル範囲）
- **右下角**: `mouth3`表情に変化（3秒後に復帰）
- **左下角**: `wink`表情に変化（3秒後に復帰）
- **右上角**: `crying`表情に変化（3秒後に復帰）

#### ドラッグ操作（撫で動作）
- **目以外の領域をドラッグ**: 撫で時間をリアルタイム計測
- **2秒以上の撫で**: 2秒ごとに`happy`または`wink`表情に段階的変化
- **撫で終了**: 1秒後に撫で時間表示が消える

#### その他のタップ操作
- **目以外の任意位置**: 瞳孔がタップ方向に移動（3秒後に中央復帰）

#### 過度なタップ防止機能
- **10秒間に10回以上の目タップ**: 自動的に`angry`または`crying`表情
- **反応時間**: 7-10秒間表情を維持
- **復帰条件**: タップ停止で`neutral`、継続タップで`hurt`表情

## 🌐 HTTP API仕様

### エンドポイント

#### 表情取得
```http
GET /expression
```

**レスポンス例:**
```json
{
  "expression": "happy"
}
```

#### 表情設定
```http
POST /expression
Content-Type: application/json

{
  "expression": "angry"
}
```

**HTTPステータス:**
- `200 OK`: 成功
- `400 Bad Request`: 無効な表情タイプ
- `500 Internal Server Error`: サーバーエラー

### 有効な表情タイプ
```json
["neutral", "happy", "angry", "sad", "surprised", "crying", "hurt", "wink", "mouth3"]
```

### curl使用例

```bash
# 現在の表情を取得
curl http://localhost:8080/expression

# 笑顔に変更
curl -X POST http://localhost:8080/expression \
  -H "Content-Type: application/json" \
  -d '{"expression": "happy"}'

# 口開け表情に変更
curl -X POST http://localhost:8080/expression \
  -H "Content-Type: application/json" \
  -d '{"expression": "mouth3"}'
```

### アニメーション詳細

#### 表情システム
- **目の制御**: まぶたの開閉、角度、サイズ調整、瞳孔の動的制御
- **口の制御**: ベジェ曲線による自然な形状変化、表情別の詳細調整
- **特殊エフェクト**: 涙アニメーション（crying表情時）、瞳孔移動制御

#### 自動アニメーション
- **瞬き**: 3-10秒間隔でランダム発生、拡大効果付き
- **頭の動き**: 微細なランダム移動（1.5px範囲）
- **呼吸効果**: サイン波による自然な上下動
- **表情変更エフェクト**: ジャンプアニメーション（高さ10-30px）

#### インタラクション機能
- **タッチ反応**: 位置別の異なる反応システム
- **撫で検出**: ドラッグ距離・時間・位置による判定
- **過度操作防止**: タップ頻度監視と自動反応
- **座標変換**: フルスクリーンモード対応の精密な当たり判定

#### レスポンシブ対応
- **16:9アスペクト比**: 画面サイズに応じて自動スケーリング
- **基準解像度**: 1920x1080での最適化
- **フルスクリーン対応**: ウィンドウサイズに合わせて調整
- **マルチタッチ無効化**: 全画面モードでの誤操作防止

## 🐛 トラブルシューティング

### よくある問題

#### 1. アプリが起動しない
```bash
# Node.jsバージョン確認
node --version  # 16.x以上が必要

# 依存関係を再インストール
rm -rf node_modules package-lock.json
npm install
```

#### 2. 表情が変わらない
- アプリケーションにキーボードフォーカスがあるか確認
- F12で開発者ツールを開いてエラーを確認
- HTTP接続設定が正しいか確認
- フルスクリーンモードでタップがずれる場合はアプリを再起動

#### 3. タッチ操作が反応しない
- タッチ位置が当たり判定範囲内か確認（Hキーで可視化）
- フルスクリーンモードでの座標のずれを確認
- 複数指でのタッチを避ける（マルチタッチは無効化済み）

#### 4. 撫で動作が検出されない
- ドラッグ距離が20ピクセル以上あるか確認
- 目の範囲外でドラッグしているか確認
- Qキーで撫で時間表示を有効にして動作確認

#### 5. HTTP接続エラー
```bash
# サーバー起動確認
curl http://localhost:8080/expression

# ポート使用状況確認
netstat -tlnp | grep :8080
```

#### 6. パフォーマンス問題
- ハードウェアアクセラレーションを有効化
- 他のアプリケーションを終了
- 開発者ツールを閉じる

### ログ確認
開発者ツール（F12）のコンソールで以下のログを確認：
- `HTTP経由で表情を{expression}に変更しました`
- `キー {key} が押されました。表情を {expression} に変更します。`
- `✅ 撫で動作条件満たしました！`
- `👁️ 目タップ回数（過去10秒）: {count}/10`
- `🔥 過度なタップ検出！`
- `フルスクリーン座標変換:` - タッチ座標の変換状況
- HTTP接続エラーメッセージ
